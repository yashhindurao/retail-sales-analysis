# Retail Sales & Business Performance Analysis

## Project Overview
This project analyzes real-world online retail transaction data to understand revenue trends, product performance, customer purchasing behavior, and geographical sales patterns.

## Objectives
- Analyze total revenue, orders, and average order value.
- Identify top-selling products and countries.
- Study monthly sales trends.
- Analyze repeat customer behavior.
- Present business insights through an interactive Power BI dashboard.

## Tools & Technologies
- Excel
- Python
- NumPy
- Pandas
- Matplotlib
- Power BI

## Project Workflow
1. Data collection from the UCI Online Retail dataset.
2. Data inspection and preprocessing.
3. Exploratory Data Analysis using Python.
4. KPI calculation and data validation.
5. Interactive dashboard development in Power BI.
6. Business recommendations based on the findings.

## Dataset
Source: UCI Machine Learning Repository — Online Retail.

The dataset contains historical online retail transactions from 2010–2011.

## Key Deliverables
- Cleaned retail transaction dataset.
- Python analysis notebook.
- EDA charts and summary files.
- Interactive Power BI dashboard.
- Business insights and recommendations.

## Limitations
The dataset does not contain product cost or stock-on-hand information. Therefore, profit margin and actual inventory levels are not calculated.
